##  Featured Projects

###  [Knowledge Graph RAG Chatbot](https://github.com/achrafdiani)
A research assistant that enriches user queries, retrieves relevant information from a Neo4j knowledge graph of arXiv papers, and generates contextual answers. Reported retrieval metrics: MRR 0.80 and Recall@K 0.80.

###  [Automated Essay Grading](https://github.com/achrafdiani/NLP-Essay-Grading-with-LSTM-BERT-and-RoBERTa)
An NLP system that evaluates essays across six criteria using LSTM, BERT, and RoBERTa. Best reported RMSE: 0.36.

###  [Reddit Community Detection](https://github.com/achrafdiani/Community-Detection-in-Reddit-Comment-Networks-with-louvain-and-agglomerative-clustering)
Graph analytics project comparing Louvain community detection with agglomerative clustering to identify communities in Reddit interaction networks.

###  [Machine Learning Algorithms from Scratch](https://github.com/achrafdiani/Machine-learning-theory-algorithms-from-scratch)
Implementations of fundamental machine learning algorithms, including classification, regression, regularization, and cross-validation.
